# Ruby Formula Calculator

Это веб-приложение на Ruby для расчета математической формулы:
\[ a \cdot x^4 + b^{1/6} \cdot x^3 + c \cdot x^2 + \dfrac{d \cdot x}{f} \]

## Установка зависимостей

```bash
bundle install
```

## Запуск приложения

```bash
ruby app.rb
```

Приложение будет доступно по адресу: http://localhost:4567

## Технологии

- Ruby
- Sinatra (веб-фреймворк)
- ERB (шаблонизатор)
- Puma (веб-сервер)

## Функциональность

- Ввод параметров a, d, f с валидацией диапазонов и шагов
- Расчет формулы с стандартной точностью Ruby Float (64 бита)
- Загрузка тестовых наборов из JSON файлов
- Сравнение с эталонными значениями
- Отображение погрешности вычислений

## Константы формулы

- B = 340
- C = 1.07
- X = ∛3 ≈ 1.4422

## Диапазоны аргументов

- a: [0.8; 1.17], шаг 0.01
- d: [2; 5.13], шаг 0.01
- f: [-12; 144], шаг 12
